Individual cow recommendations

Data completeness legend

Pregnancy = pregnancy diagnosis missing. BCS = body condition score missing. Expected calving = expected calving date missing for a cow that is not recorded as Empty. Empty cows do not require an expected calving date. Partial SCC = one or more expected current-season herd-test SCC results are missing or recorded as 0.

How dry-off advice is calculated

BCS + expected calving date: uses the BCS-adjusted timing calculation. Expected calving date only: if BCS is missing, uses a 50-day dry period before the expected calving date. No expected calving date: dry-off timing is unavailable.
